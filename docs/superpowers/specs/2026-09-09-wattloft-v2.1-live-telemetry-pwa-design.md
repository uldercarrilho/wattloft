# Wattloft v2.1: Live Telemetry, Zero-Polling SSE & PWA Shell

Wattloft observes production of one household solar Plant. This specification details **Milestone 2 (v2.1)** of the Wattloft roadmap, introducing real-time telemetry streaming, an installable Progressive Web App (PWA) with offline resilience, and daylight logger stall alerting via Web Push.

---

## 1. Goal

1. **Zero-Polling Live Telemetry:** Replace the 20-second client polling loop with Server-Sent Events (SSE). When an admitted Logger pushes a frame on Server B, the Plant view updates within milliseconds.
2. **PWA Offline Resilience:** Provide a Service Worker that caches the Azulejo application shell and the last known plant state. Opening the app without connectivity immediately displays cached data with a quiet status indication.
3. **Daylight Stall Notifications:** Deliver proactive Web Push notifications if an admitted Logger falls silent during daylight producing hours, alerting the Operator before daylight production is lost.
4. **Preserve Domain Boundaries:** Single household plant, single Operator, Azulejo aesthetic, no third-party cloud telemetry or analytics services.

---

## 2. Non-Goals

- Multi-tenant notifications or external alerting services (e.g. Twilio, PagerDuty, Sendgrid).
- Two-way WebSocket protocol (SSE is unidirectional and simpler over HTTP/2 and reverse proxies).
- Client-side data writes or remote inverter control.
- Changes to the underlying Solarman V5 ingest wire protocol.

---

## 3. Architecture & Data Flow

```
Logger (TCP 10000)
       │
       ▼
wattloft.ingest (Python)
  ├─> records Sample to MySQL
  └─> broadcasts event to Ingest Bus (loopback HTTP/SSE on 127.0.0.1:8000/events)
            │
            ▼
plant-view BFF (Node / Hono on 127.0.0.1:3000)
  ├─> subscribes to Python /events
  ├─> evaluates Stall & Web Push rules
  └─> exposes GET /api/plant/stream (Authenticated SSE)
            │
            ▼
Operator Browser (via Caddy HTTPS 443)
  ├─> React UI: EventSource('/api/plant/stream')
  ├─> Service Worker: offline caching & push listener
  └─> Azulejo UI: live Power ticks, quiet offline banner
```

## 4. Component Details

### 4.1 Ingest Event Broadcaster (Python)
- `src/wattloft/api.py` exposes `GET /events` bound to `127.0.0.1:8000`.
- An in-process `asyncio.Queue` fans out new sample arrivals to connected subscribers.
- Event payload:
  ```json
  {
    "type": "sample",
    "logger_serial": "3909309465",
    "received_at": "2026-09-09T14:32:00Z",
    "ac_power_w": 412.5,
    "today_energy_kwh": 3.82,
    "lifetime_energy_kwh": 1420.15
  }
  ```

### 4.2 Node BFF Stream & Push Engine (`plant-view/src/server.ts`)
- **Route:** `GET /api/plant/stream`
  - Validates Operator session cookie.
  - Returns `Content-Type: text/event-stream`, `Cache-Control: no-cache`, `Connection: keep-alive`.
  - Pushes initial state upon connection (`event: snapshot`), followed by incremental sample events (`event: sample`).
  - Emits a heartbeat comment (`: ping`) every 30 seconds to prevent proxy connection timeouts.
- **Web Push Subscription Management:**
  - `POST /api/notifications/subscribe`: Saves the Operator's Web Push subscription into a secured table or secret vault.
  - VAPID keys loaded from Vault (`OPERATOR_VAPID_PUBLIC_KEY`, `OPERATOR_VAPID_PRIVATE_KEY`).

### 4.3 React Client Live Stream Hook
- `plant-view` connects via `EventSource('/api/plant/stream')`.
- On `sample` event:
  - Updates `Current Power` and `current_power_at` instantaneously.
  - Updates corresponding row in `loggers_now`.
  - In Time grain, appends or updates the active minute's point on the Power curve.
- **Fallback:** If `EventSource` fails or errors repeatedly (3 retries with exponential backoff), the client cleanly falls back to the existing 20-second polling behavior.

### 4.4 Service Worker & Offline PWA
- **Manifest:** `manifest.webmanifest` enhanced with standalone display mode, orientation `any`, and SVG icons matching the Azulejo palette.
- **Service Worker (`sw.ts`):**
  - **Pre-caches:** HTML shell, CSS, bundled JavaScript, Web Fonts (`Source Sans 3`, `Ibarra Real Nova`, `IBM Plex Mono`), and icons.
  - **Stale-While-Revalidate:** Intercepts `/api/plant` requests. If offline or network times out (> 3 seconds), returns cached JSON snapshot.
- **Azulejo Offline Indicator:**
  - When rendering cached data while `navigator.onLine === false`, displays a subtle banner beneath header:
    `Offline · Showing cached plant state as of 14:32`.

### 4.5 Daylight Logger Stall Web Push Alert
- A background tick runs every 5 minutes in the Node process.
- **Alert Condition:**
  - Time is between 07:00 and 18:00 Local Time (`America/Sao_Paulo`).
  - One admitted Logger has had no successful sample for $> 20$ minutes.
  - Sibling Logger is actively reporting with `ac_power_w > 50 W` (confirming ambient sunlight is available).
  - An alert has not already been sent today for this event.
- **Notification Payload:**
  - Title: `Wattloft · Logger Stall`
  - Body: `West logger has been silent for 20m while East is producing 420 W.`
  - Icon: `/favicon.svg`

## 5. Security & Privacy

- `GET /api/plant/stream` requires the same `wattloft` session cookie as `/api/plant`.
- Web Push subscriptions are protected by VAPID authentication and restricted strictly to the single Operator.
- All service worker caches are scoped to the origin and cleared on logout.
