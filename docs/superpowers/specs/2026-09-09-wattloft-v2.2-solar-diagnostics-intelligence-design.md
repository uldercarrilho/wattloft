# Wattloft v2.2: Solar Diagnostics & Production Intelligence

Wattloft observes production of one household solar Plant. This specification details **Milestone 3 (v2.2)** of the Wattloft roadmap, adding solar production diagnostics: panel drift tracking, inverter clipping identification, an astronomical clear-sky baseline envelope, and year-over-year production comparisons.

---

## 1. Goal

1. **Array Balance & Drift Tracker:** Compare the relative daily performance of physical microinverter strings (East vs. West) to detect soiling, partial shading, or diode/panel degradation over time.
2. **Clipping & Throttle Detection:** Detect when microinverters hit their peak AC output ceiling or thermal limit, calculating estimated clipped energy without external sensors.
3. **Clear-Sky Ideal Envelope:** Compute an astronomical solar irradiance baseline for the Plant's rooftop geometry to visually ground daily curves against theoretical potential.
4. **Historical Period Comparison:** Enable the Operator to compare any Local Day, Month, or Year against historical benchmarks (e.g. same month last year).
5. **Preserve Domain Boundaries:** Zero third-party cloud weather APIs or telemetry leaks; all calculations run locally in Wattloft.

---

## 2. Non-Goals

- Complex 3D roof raytracing or shadow modeling software.
- Battery, consumption, or utility grid billing calculations.
- Vendor inverter firmware modifications.

---

## 3. Diagnostics Modules

### 3.1 Array Balance & Drift Tracker

#### Mathematical Formulation
For each Local Day $d$ with successful production from both admitted loggers (e.g. East and West):
$$\text{Ratio}(d) = \frac{\text{TodayEnergy}_{\text{East}}(d)}{\text{TodayEnergy}_{\text{West}}(d)}$$

Wattloft tracks a 30-day rolling median $\bar{R}_{30}(d)$ against the baseline established during the first 60 days of monitoring ($R_{\text{base}}$).

#### Drift Detection Rule
If $|\bar{R}_{30}(d) - R_{\text{base}}| / R_{\text{base}} > 0.12$ continuously for 14 Local Days:
- A non-intrusive advisory badge appears in the logger list:
  `East array underperforming relative to West by 14% (check for soiling or obstruction)`.
- If both loggers drop equally (e.g. winter solstice or prolonged rain), the ratio remains stable, preventing false alarms from weather variations.

---

### 3.2 Inverter Clipping & Thermal Throttle Identification

#### Clipping Characteristics
Microinverters exhibit a distinct flat-top signature when DC panel generation exceeds maximum AC inverter capacity or when thermal throttling caps output.

#### Plateau Detection Algorithm
In the Time curve of a Local Day:
1. Identify contiguous periods $\ge 45$ minutes where:
   $$\max(\text{watts}) - \min(\text{watts}) \le 0.015 \times \text{nameplate\_w}$$
   and $\text{watts} \ge 0.90 \times \text{nameplate\_w}$.
2. If the solar elevation angle is increasing or at peak zenith during this period, mark the window as **clipping**.
3. **Clipped Energy Estimation:** Fit a standard sinusoidal bell curve across the plateau endpoints to estimate uncaptured energy:
   $$\text{Energy}_{\text{clipped}} = \int (P_{\text{ideal}}(t) - P_{\text{actual}}(t)) \, dt$$

#### UI Presentation
In the Time grain curve:
- The curve line across the clipping plateau renders with a subtle top highlight (`--logger-a` tint).
- Scrubbing the hair across this plateau displays:
  `12:45 · 998 W (clipped · est. 0.35 kWh lost today)`.

---

### 3.3 Clear-Sky Ideal Envelope Model

#### Offline Solar Geometry
Using the Plant's configured rooftop coordinates:
- Solar position algorithm (zenith $\theta_z$, azimuth $\gamma_s$) calculated from date, time, latitude, and longitude.
- Haurwitz clear-sky global horizontal irradiance model:
  $$I_{\text{clear}} = 1098 \cdot \cos(\theta_z) \cdot \exp\left(-\frac{0.057}{\cos(\theta_z)}\right) \quad (\text{for } \theta_z < 85^\circ)$$
- Scaled to the Plant's total peak nameplate DC capacity ($W_p$).

#### UI Presentation
- Displayed as an optional, whisper-quiet dashed guideline (`--muted` with 30% opacity) on the Time grain curve.
- Enabled via a subtle toggle beside the Each / By Logger mode switch: `Ideal envelope`.
- Allows the Operator to instantly see whether a dip in production was due to cloud passing or equipment anomaly.

---

### 3.4 Historical Period Comparison Overlays

#### Year-Over-Year Comparison Bars
- In **Month grain**: each day bar shows a ghosted hairline beside it representing production on the exact same calendar day of the previous year (if History covers it).
- In **Year grain**: each month bar displays the percentage delta relative to the previous year:
  `Nov 2026: 342 kWh (+8% vs 2025)`.

## 4. Schema & Data Model Updates

No additional raw tables are required. The diagnostics engine operates efficiently on `day_summaries` (from v2.0):
- Add optional columns to `day_summaries`:
  ```sql
  ALTER TABLE day_summaries
      ADD COLUMN clipped_minutes INT NOT NULL DEFAULT 0,
      ADD COLUMN estimated_clipped_kwh DOUBLE DEFAULT NULL;
  ```
- Rolling ratios and comparisons are computed dynamically by the Python snapshot engine in $< 5\text{ms}$ over the compact `day_summaries` dataset.

## 5. UI/UX Azulejo Consistency

- All visual additions strictly obey the existing Azulejo design system:
  - Palette: `--paper` (`#E8EEF2`), `--ink` (`#1A2A3A`), `--pigment` (`#1E4F8C`), `--logger-a`, `--logger-b`.
  - Typography: `IBM Plex Mono` for metric readouts; `Source Sans 3` for labels.
  - No flashy warning icons, modals, or alarm banners; all diagnostic feedback is calm, textual, and informational.

## 6. Verification & Test Plan

1. **Drift Model Unit Tests:**
   - Synthetic datasets simulating symmetric panel degradation vs. single-string soiling; verify drift alert triggers only on genuine sustained divergence.
2. **Clipping Algorithm Tests:**
   - Real-world sunny-day curves with 1 kW plateaus; assert correct start/end minute detection and numerical integration of clipped kWh.
3. **Clear-Sky Baseline Precision:**
   - Assert computed solar noon and zenith angles match NOAA solar calculations within $\pm 0.5\%$.
4. **Chart Visual Tests:**
   - Vitest tests for `PlantChart.tsx` ensuring optional clear-sky dataset renders cleanly without breaking stacked bar or overlay curve modes.
